## 1. Concept of ML

### 기계 학습(Machine Learning)의 기본 개념

- 러닝(Learning): 코드를 직접 수정하지 않고, 데이터를 통해 프로그램의 성능을 향상시키는 과정.

- 가설(Hypothesis): 주어진 문제를 해결하기 위해 설정하는 수학적 모델.

- 선형 회귀(Linear Regression): H(x) = Wx + b 와 같은 직선의 방정식으로 데이터를 예측하는 모델. 연속된 숫자 예측에 사용.

- 다중 선형 회귀(Multiple Linear Regression): H(x) = W1x1 + W2x2 + ... + Wnxn + b 와 같은 다차원 직선의 방정식으로 데이터를 예측하는 모델. 여러 개의 독립 변수를 사용하여 종속 변수를 예측.

- 로지스틱 회귀(Logistic Regression): 시그모이드(Sigmoid) 함수를 사용해 결과를 0과 1 사이의 확률 값으로 변환하는 모델. 참/거짓(True/False)과 같은 분류(Classification) 문제에 사용.

$$sigmoid(x) = \frac{1}{1 + e^{-x}}, z = Wx + b$$

---

### 비용 함수 (Cost Function)

- 정의: 모델의 예측값과 실제 정답 값 사이의 오차(Error)를 측정하는 함수. 이 비용(Cost)을 최소화하는 것이 학습의 목표.

- 선형 회귀의 비용 함수: 평균 제곱 오차(Mean Squared Error, MSE)를 주로 사용.
    - 오차를 제곱하여 부호를 없애고, 미분이 가능하도록 만든다.

$$Cost(W) = \frac{1}{m}\sum_{i=1}^{m}((W x^{(i)}) - y^{(i)})^2$$

- 로지스틱 회귀의 비용 함수: 바이너리 크로스 엔트로피(Binary Cross-Entropy, BCE)를 사용.
    - MSE를 사용하면 many local minimum이 발생하여 최적의 파라미터를 찾기 어려움.
    - 로그(log) 함수를 활용하여 모델의 예측이 정답이면 0, 정답에서 멀어질수록 비용이 커지도록 설계.

$$Cost(W) = \frac{1}{m} \sum_{i=1}^{m} c(H(x^{(i)}), y^{(i)})$$
$$c(H(x), y) = \begin{cases} -\log(H(x)) & : y = 1 \\ -\log(1 - H(x)) & : y = 0 \end{cases}$$

$$c(H(x), y) = -y\log(H(x)) - (1-y)\log(1-H(x))$$

$$Cost(W) = -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)}\log(H(x^{(i)})) + (1-y^{(i)})\log(1-H(x^{(i)}))]$$

### 경사 하강법 (Gradient Descent)

- 정의: 비용 함수를 최소화하는 최적의 파라미터(W, b)를 찾기 위한 알고리즘.

$$W := W - \alpha \frac{1}{m}\sum_{i=1}^{m}(W x^{(i)} - y^{(i)})x^{(i)} = W - \alpha \frac{d}{dW}Cost(W)$$

- 핵심 원리: 비용 함수의 기울기(Gradient)를 계산하여, 기울기가 가장 가파르게 감소하는 방향으로 파라미터를 점진적으로 업데이트.

- 학습률(Learning Rate, α): 파라미터를 얼마나 큰 폭으로 업데이트할지 결정하는 값.
    - 너무 크면 최적점을 지나치고, 너무 작으면 학습이 느려진다.
    - 업데이트 공식: W := W - α * (비용 함수의 미분값)

- 배치(Batch)와 에포크(Epoch):
    - 에포크(Epoch): 전체 데이터셋을 한 번 학습하는 단위.
    - 배치(Batch): 대용량 데이터를 작은 묶음으로 나누어 학습하는 단위.
    - 확률적 경사 하강법(Stochastic Gradient Descent, SGD): 전체 데이터가 아닌, 랜덤하게 추출된 배치 단위로 학습하여 속도를 높이는 방식.
