## 2. Artificial Neural Network (ANN)

### ANN의 정의 및 생물학적 배경

- **정의**: 인간의 두뇌 구조를 모방하여 수많은 간단한 처리기(뉴런)의 네트워크를 통해 문제를 해결하는 기계학습 모델.

- **생물학적 뉴런 vs 수학적 모델링**:
    - **수상돌기(Dendrites)**: 외부 신호 수용 → **입력값 ($x_1, x_2, ..., x_n$)**
    - **시냅스(Synapse)**: 신호 전달 접점 → **가중치 ($w_1, w_2, ..., w_n$)**
    - **세포체(Cell body)**: 신호 처리 → **가중합($\Sigma$) 및 활성화 함수($f$)**
    - **축색돌기(Axon)**: 처리 결과 전달 → **출력값 ($o$)**

- **작동 원리**:
    - 가중합: $net = \sum w_i x_i$
    - 최종 출력(활성화 함수 통과): $o = \sigma(net) = \frac{1}{1 + e^{-net}}$

- **학습 (델타 규칙, Delta Rule)**: 실제 정답($y^*$)과 모델 출력($y$)의 차이(Error)를 가중치 조정에 반영.
    - $w' = w + r(y^* - y)x$ (여기서 $r$은 학습률)

---

### 인공신경망의 역사 (Brief History)

1.  **1957년 (Frank Rosenblatt)**: **단층 퍼셉트론(Single-layer Perceptron)** 고안.
2.  **1969년 (Minsky & Papert)**: 단층 퍼셉트론의 **XOR 문제 해결 불가** 증명 → **1차 AI 빙하기**.
3.  **1986년 (Rumelhart & Hinton)**: 다층 퍼셉트론(MLP)과 **역전파(Backpropagation)** 알고리즘 발표.
    - 층이 깊어지면 기울기가 사라지는 **Vanishing Gradient** 문제 발생 → **2차 AI 빙하기**.
4.  **2009년~현재 (Hinton 등)**: **ReLU** 활성화 함수(Vanishing Gradient 해결) 및 **Drop-out**(과적합 방지) 도입 → **딥러닝의 부흥**.

---

### 다항 분류 (Multinomial Classification)

- **개념**: 여러 개의 클래스를 분류할 때, 이를 여러 개의 이진 분류(Binary Classification) 문제로 쪼개어 해결.
    - 예: A인가? B인가? C인가?를 각각 독립적인 결정 경계(직선)로 처리.

- **SoftMax 함수**: 선형 연산 결과인 점수(Scores)를 **확률값(Probabilities)**으로 변환.
    - 모든 출력값은 0~1 사이이며, 총합은 항상 **1**이 됨.
    - $S(y_i) = \frac{e^{y_i}}{\sum_j e^{y_j}}$

- **One-hot Encoding**: SoftMax 확률값 중 가장 큰 인덱스만 1, 나머지는 0으로 표현하는 방식 (예: $[1, 0, 0]$).

- **크로스 엔트로피(Cross Entropy) 비용 함수**:
    - 정답과 예측이 일치하면 0, 틀릴수록 무한대에 가까운 페널티 부여.
    - $D(S, L) = -\sum_i L_i \log(S_i)$ ($S$: 예측 확률, $L$: 실제 정답 One-hot 벡터)

---

### 비선형 문제와 다층 퍼셉트론 (MLP)

- **한계**: 단일 퍼셉트론은 직선 하나로 공간을 나누므로, XOR와 같은 비선형 문제를 풀 수 없음.
- **해결 (MLP)**:
    1.  **Hidden Layer(은닉층)** 추가: 입력 데이터의 공간을 변환.
    2.  **비선형 활성화 함수(Sigmoid 등)** 사용: 데이터를 선형 분리가 가능한 새로운 좌표 공간으로 매핑.
    3.  **출력층**: 변환된 공간에서 선형 분리를 수행하여 최종 결과 도출.

---

### PyTorch를 이용한 신경망 구현 (XOR 예제)

- **모델 설계 (nn.Sequential)**:
    - `nn.Linear(2, 2)`: 입력(2개) → 은닉층(2개)
    - `nn.Sigmoid()`: 은닉층 활성화 함수
    - `nn.Linear(2, 1)`: 은닉층(2개) → 출력(1개)
    - `nn.Sigmoid()`: 출력층 활성화 함수 (0~1 사이 확률값)

- **핵심 설정**:
    - **비용 함수**: `nn.BCELoss()` (Binary Cross Entropy) - 이진 분류에 최적화.
    - **옵티마이저**: `torch.optim.SGD` (확률적 경사 하강법).

- **학습 루프 (Training Loop)**:
    1. `optimizer.zero_grad()`: 이전 기울기 초기화.
    2. `hypothesis = model(input)`: 순전파(Forward).
    3. `cost = loss_func(hypothesis, labels)`: 오차 계산.
    4. `cost.backward()`: 역전파(Backward) - 기울기 계산.
    5. `optimizer.step()`: 가중치 업데이트.

- **평가 모드**: `model.eval()` 호출 및 `with torch.no_grad()` 블록 사용 (기울기 계산 비활성화로 자원 절약).

---

### 신경망의 깊이(Depth)와 너비(Width)

- **Wide ANN**: 은닉층의 노드 수를 늘리는 것. 결정 경계(선)의 개수를 늘려 표현력을 높임. 수렴 속도가 빨라지나 연산량이 증가함.
- **Deep ANN**: 은닉층의 개수(층)를 늘리는 것. 공간을 왜곡하고 선을 구부리는 효과를 주어 복잡한 비선형 문제를 해결.
- **Deeper의 문제**: 층이 너무 깊어지면 학습이 오히려 안 되는 현상 발생 (**기울기 소실**).

---

### 기울기 소실(Vanishing Gradient)과 활성화 함수

- **원인**: **Sigmoid** 함수의 미분값은 최대 0.25임. 역전파 시 연쇄 법칙(Chain Rule)에 의해 이 작은 값들이 계속 곱해지면서 입력층에 가까워질수록 기울기가 0에 수렴하여 학습이 중단됨.

- **해결책 (ReLU)**: $f(x) = \max(0, x)$
    - 양수 구간의 미분값이 항상 **1**이므로 깊은 층에서도 기울기가 보존됨.
    - **주의**: 출력층은 확률값(0~1) 계산을 위해 여전히 Sigmoid를 사용해야 함.

- **기타 활성화 함수**:
    - **TanH**: 출력 범위 -1 ~ 1, Zero-centered 되어 학습 효율이 좋음.
    - **Leaky ReLU**: 입력이 음수일 때 0이 되어 뉴런이 죽는 'Dying ReLU'를 방지하기 위해 작은 기울기 부여.

---

### 과적합(Overfitting) 방지 및 정규화(Regularization)

- **Underfitting**: 모델이 너무 단순하여 패턴을 못 찾음 (해결: 모델 복잡도↑, 학습↑).
- **Overfitting**: 훈련 데이터에 과하게 맞춰져 새로운 데이터 예측 성능 저하 (해결: 데이터 추가, 특성 감소, 정규화).

- **정규화 기법**:
    - **L1 (Lasso)**: 가중치 절댓값 합을 패널티로 추가. 불필요한 가중치를 0으로 만듦 (특징 선택 효과, Sparse Model에 적합).
    - **L2 (Ridge)**: 가중치 제곱합을 패널티로 추가. 가중치를 전반적으로 작게 유지 (가장 널리 쓰임).
    - **Dropout**: 학습 과정 중에서 무작위로 뉴런 연결을 끊음. 특정 뉴런 의존도를 낮추고 앙상블 효과 유도. (**평가 시에는 모든 뉴런 사용 필요**)
    - **Early Stopping**: 검증 오차가 다시 증가하기 시작하는 시점에서 학습 조기 종료.

---

### 최신 기법 및 구현 패턴

- **잔차 연결 (Residual Connection)**: 입력 $X$를 가중합 결과에 직접 더해주는 구조($F(X) + X$).
    - 역전파 시 기울기 경로를 확보하여 Vanishing Gradient 문제를 완화, 수백 층의 깊은 망 학습 가능.

- **클래스 기반 구현 (nn.Module)**:
    - `__init__`: 레이어(Linear) 및 하이퍼파라미터 정의.
    - `forward`: 데이터의 흐름(순전파) 정의.
    - **장점**: 모델 구조를 객체지향적으로 체계화하여 관리 가능.

- **모델 관리**: `torch.save(model.state_dict(), path)`를 통해 가중치 정보만 저장하고, `load_state_dict`로 재사용하는 것이 권장됨.
