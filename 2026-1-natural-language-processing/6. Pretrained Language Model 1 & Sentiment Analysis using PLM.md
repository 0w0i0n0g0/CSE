## 6. Pretrained Language Model & Sentiment Analysis

### 전이 학습 (Transfer Learning)
- **개념**: 사전 작업(source task)에 대하여 학습된 정보를 목표 작업(target task)에 활용하는 방법입니다.
- **특징**: 학습 데이터가 부족해도 목표 작업에 대한 수렴 속도 및 성능 향상을 꾀할 수 있습니다.
- **전이 학습의 유형**: 
  - **Domain Adaptation**: 서로 다른 도메인에서 동일한 작업을 수행할 때 활용 (예: 영화평 분류 모델을 상품평 분류에 활용).
  - **Cross-lingual Learning**: 서로 다른 언어 간의 동일한 작업 수행 (예: 일영 번역 모델을 일한 번역에 활용).
  - **Multi-task Learning**: 사전 작업과 목표 작업이 동시에 이루어지는 전이 학습 (예: 형태소 분석 및 개체명 인식 결합 모델).
  - **Sequential Transfer Learning**: 사전 작업과 목표 작업이 다르고 각 작업에 대하여 순차적으로 학습을 수행하는 방식 (예: 언어 모델 학습 결과를 기계 독해에 활용).
- **순차 전이 학습(Sequential Transfer Learning)의 활용**:
  - 사전 작업과 목표 작업에 대한 데이터를 동시에 사용할 수 없는 경우나 사전 작업 학습 데이터가 더 많은 경우에 사용합니다.
  - 대용량 사전 학습 언어 모델(BERT, GPT, ALBERT, ROBERTa, ELECTRA, XLNet 등)이 이를 기반으로 하며, 다양한 NLP 문제에서 SOTA(State-Of-The-Art) 성능을 획득했습니다.

### 언어 모델 아키텍처 비교: Auto Encoding vs. Auto Regressive
- **Auto Encoding (AE)**:
  - BERT는 문장 내 코럽트된(Corrupted) 시퀀스를 예측하는 Denoising AE 모델로 볼 수 있습니다.
  - $\hat{x}=[x_{1},[MASK],\cdot\cdot\cdot,x_{T}]$ 처럼 일부 단어를 마스킹하고 이를 예측하도록 학습합니다.
  - 우도(Likelihood)는 $p(\overline{x}|\hat{x})\approx\prod_{t=1}^{T}p(x_{t}|\hat{x})$와 같이 계산되며, 마스킹된 부분의 예측에 초점을 둡니다.
- **Auto Regressive (AR)**:
  - 이전 시점의 단어들을 기반으로 다음 단어를 순차적으로 예측하는 구조입니다.
  - 우도(Likelihood)는 $p(x)=\prod_{t=1}^{T}p(x_{t}|x_{<t})$ 로 계산됩니다.
  - 목적 함수는 $Max_{\theta}logp_{\theta}(x) = \sum_{t=1}^{T}logp_{\theta}(x_{t}|x_{<t})$ 로 구성됩니다.

### BERT (Bidirectional Encoder Representations from Transformers)
- **개념 및 구조**: 
  - 양방향(Bidirectional) 트랜스포머 인코더 블록을 사용하여 언어 자체를 깊이 이해하도록 학습된 Task Agnostic 모델입니다.
  - **BERT-Base**: $L=12$, $A=12$, $H=768$, 총 파라미터 수 $110M$.
  - **BERT-Large**: $L=24$, $A=16$, $H=1024$, 총 파라미터 수 $340M$.
- **입력 표현 (Input Representation)**: 
  - Token Embeddings, Segment Embeddings, Position Embeddings를 합산하여 구성합니다.
  - 문장의 시작은 항상 `[CLS]` 토큰으로, 문장의 끝이나 구분은 `[SEP]` 토큰으로 표시합니다.
- **사전 학습 방법 (Pre-Training)**:
  - **Masked LM**: 무작위 토큰의 15%를 선택하여, 80%는 `[MASK]`로 변경, 10%는 임의의 단어로 변경, 10%는 원본 단어를 유지하여 문맥 내 단어를 예측하게 합니다.
  - **Next Sentence Prediction (NSP)**: 주어진 두 문장이 연속된 문장인지 예측하며, 50%는 실제 연속된 문장, 50%는 랜덤 문장으로 학습하여 전이 학습(QA, NLI 등)에 기여합니다.
  - **데이터셋**: Book Corpus (800M 단어)와 English Wikipedia (2,500M 단어)를 사용하였습니다.

### 사전 학습 모델의 발전 (History of Pretrained LMs)
- **GPT-1**: Transformer Decoder 블록을 단방향으로 사용하여 문맥을 파악합니다.
- **GPT-2**: Task Agnostic을 통해 제로샷(Zeroshot) 학습을 도입하여 파인튜닝 없이도 좋은 성능을 냈습니다.
- **XLNet**: BERT 모델 이후 큰 성능향상을 보였으며 $AE+AR$의 개념을 도입했습니다.
- **ROBERTa**: BERT가 아직 과소적합(Underfit)되었다고 보고 만들어진 최적화된 BERT 모델입니다.
  - 학습 시간, 배치 사이즈, 학습 데이터를 대폭 늘려 Downstream task 성능을 향상시켰습니다.
  - 사전 학습 단계에서 Next sentence prediction을 제거하고, 더 긴 시퀀스를 추가했으며 동적(Dynamic) 마스킹 패턴을 도입했습니다.
  - 구조적 변화 없이 모델 최적화만으로 다른 모델 대비 높은 성능을 기록했습니다.
- **MASS & BART**: 인코더와 디코더에 노이즈/상반된 마스킹을 적용하여 모델 성능을 올렸습니다.
- **T5**: Text-to-text 프레임워크를 사용하여 모든 NLP task를 통합할 수 있는 Encoder-Decoder Transformer 구조를 띕니다.

---

### 사전 학습 언어 모델 분류 체계 (PTM Taxonomy)
- **구조에 따른 분류 (Architectures)**: LSTM, Transformer Encoder (예: BERT, ROBERTa), Transformer Decoder (예: GPT-1, GPT-2), Full Transformer (예: MASS, BART) 등으로 나뉩니다.
- **확장 모델 (Extensions)**:
  - **Knowledge-Enriched**: 외부 지식을 포함 (예: ERNIE, KnowBERT).
  - **Multilingual & Language-Specific**: 다국어 지원 (예: mBERT) 혹은 특정 언어 특화 모델 (예: BERT-wwm-Chinese, CamemBERT).
  - **Multi-Modal**: 이미지나 비디오, 음성 데이터를 함께 다룸 (예: VisualBERT, VideoBERT, SpeechBERT).
  - **Model Compression**: 경량화 모델 (예: ALBERT, DistilBERT, TinyBERT).

### 실습: 사전 학습 모델(PLM)을 활용한 감성 분석 (Sentiment Analysis)
- **과업 목적**: 대용량 언어 모델인 BERT-Base를 활용하여 입력된 한글 문장의 긍정/부정을 분류하는 감성 분석 모델을 구축합니다.
- **모델 구조**: 
  - 워드피스 기반의 한글 문장 토큰 열을 입력으로 받습니다 (`_아 더 빙..진짜 짜증 나 네요_목소리 negative` 등).
  - `[CLS]` 토큰이 문장의 맨 앞에, `[SEP]` 토큰이 맨 마지막에 위치하도록 추가합니다.
  - BERT 모델의 출력 중 `outputs[0]`에서 첫 번째 토큰인 `cls_vector`를 추출하고, 이를 완전 연결 레이어(FNN/Linear Layer)를 거쳐 Negative(N) 또는 Positive(P)로 분류합니다.
- **데이터 전처리 및 학습 과정**:
  - `KoBertTokenizer`를 사용하여 문장을 토큰화 및 ID(Index)로 치환하고, 모자란 부분은 `pad_token`을 활용해 `max_length`에 맞춰 패딩 처리합니다.
  - PyTorch의 `DataLoader`와 `Adam` Optimizer, 손실 함수로 `CrossEntropyLoss`를 적용하여 네트워크를 역전파(Backpropagation) 학습합니다.
  - 예측 평가 시에는 `torch.no_grad()`로 가중치를 고정하고 `softmax`와 `argmax`를 사용해 최종 클래스를 예측 및 검증합니다.
