## 3. Text Representation

### 이산 표현 (Discrete Representation)
- **원-핫 인코딩 (One-hot Encoding)**: 단어를 벡터로 표현하는 가장 간단한 방법론입니다. 단어 사전(dictionary)을 구성하고 해당 단어 위치의 값만 1로, 그 밖의 단어는 0으로 표현합니다.
- **한계점**:
    - **대용량 메모리 필요**: 사전의 크기만큼 차원이 커지므로 대용량 메모리가 요구됩니다 (예: 구글 1T 말뭉치의 경우 13M 차원).
    - **단어 간 유사성 비교 불가**: 벡터 간 내적(AND 연산)이 항상 0이 되어 단어 간 유사성을 비교할 수 없습니다 (예: 개, 늑대, 잉어가 모두 동일하게 취급됨).

### 분산 표현 (Distributed Representation)
- **개념**: 단어를 문맥(Context)에 기반하여 표현하는 방법입니다.
- **특징**: "비슷한 문맥에서 등장하는 단어는 비슷한 의미를 가질 것"이라는 가정에서 출발합니다. 이 방식을 사용하면 단어 벡터 간 요소의 구성이 비슷해지므로 유사도(Sim) 계산 시 0이 아닌 값을 가질 수 있습니다 (예: 코로나, 메르스).

### 공기 행렬 (Co-Occurrence Matrix)과 코사인 유사도
- **공기 행렬**: 일정한 윈도우 크기(Window size) 내에서 단어들이 함께 등장한 횟수를 기반으로 행렬을 구성합니다.
- **코사인 유사도 (Cosine Similarity)**: 길이로 정규화된 내적을 바탕으로 두 벡터 사이의 유사도를 측정하는 척도입니다.
    - 두 벡터의 구성이 비슷하면 큰 값을 가집니다.
    - 두 벡터가 동일하면 1을, 직각이면 0을 반환합니다.
    - 계산식: 
$$cos(\vec{X},\vec{Y})=\frac{\vec{X}\cdot\vec{Y}}{|\vec{X}||\vec{Y}|}$$

### 특이값 분해 (SVD; Singular Value Decomposition)
- **차원의 저주와 희소 데이터**: 차원이 증가하면서 학습 데이터의 수가 차원의 수보다 적어지면 성능이 저하되는 현상이 발생합니다 (희소 데이터 문제).
- **개념**: 행렬을 특정한 구조($X = U S V^T$)로 분해하여 근사치(Approximation)를 찾는 방식입니다.
- **한계점**:
    - $O(mn^2)$의 복잡도를 가지므로 계산에 너무 오랜 시간이 소요됩니다.
    - 새로운 단어나 문서가 추가될 경우 전체 행렬에 대해 SVD를 처음부터 다시 수행해야 하므로 유연성이 떨어집니다.

### Word2Vec
- **등장 배경**: SVD의 계산 효율성 한계를 극복하기 위해, 오차 역전파(Back-propagation)를 통해 표현을 학습하는 신경망 기반 언어 모델이 도입되었습니다. 고차원의 원-핫 벡터를 저차원 실수 벡터로 축소 및 투영합니다.
- **학습 모델**:
    - **CBOW**: 여러 주변 문맥 단어(Context)들을 이용해 하나의 중심 단어(Center word)를 예측합니다.
    - **Skip-Gram**: 하나의 중심 단어를 이용해 주변 단어들을 예측합니다.
- **구조 및 특징**:
    - **비용 함수**: 다중 클래스 분류를 위해 SoftMax 함수와 교차 엔트로피(Cross Entropy)를 사용합니다.
$$H(\hat{y},y)=-\sum_{j=1}^{|V|}y_j\log(\hat{y}_j)$$

- **계산량 최적화 기법**: V 크기만큼의 방대한 Softmax 연산을 최적화하기 위해 Hierarchical SoftMax, Negative Sampling, Sub-Sampling Frequent Words 등의 기법을 사용합니다.

### GloVe (Global Vectors)
- **개념**: 단어의 동시 등장 확률의 비율(Ratio of co-occurrence probabilities)이 의미를 인코딩할 수 있다는 핵심 아이디어를 활용한 모델입니다.
- **특징**: 단어 벡터 학습 시 전체 말뭉치에 대한 전역 통계 정보(Global information)를 반영합니다.
- **목적 함수**: 두 단어 벡터의 내적이 동시 등장 확률의 로그값과 같아지도록 로그 이중선형 모델(Log-bilinear model)을 학습시킵니다.
$$w_i \cdot w_j = \log P(i|j)$$

### 문맥 반영 임베딩 및 기타 텍스트 표현 기법
- **fastText**: 단어를 부분 단어(Subword) 단위로 쪼개어 학습하므로 미등록어(OOV)와 오탈자 같은 노이즈에 강합니다.
- **문맥 반영(Add Contexts)**: 다의어 문제를 해결하기 위해 문맥을 반영한 임베딩을 생성합니다.
    - **CoVe**: MT-LSTM을 이용해 문맥에 따른 사전학습을 수행합니다.
    - **ELMo**: RNN(BiLSTM) 기반의 언어 모델(Language Model)을 통한 사전학습으로 문맥을 반영하며, 다양한 자연어 처리 과제(SQuAD, NER 등)에서 성능을 크게 향상시켰습니다.
- **Embedding Layer**: 파이토치에서는 `nn.Embedding()`을 사용하여 단어의 정수 인덱스를 룩업 테이블(Lookup Table)을 통해 임베딩 벡터로 변환합니다. 모델 훈련 시 학습 과정에서 임베딩 벡터가 가중치처럼 함께 업데이트(파인 튜닝)됩니다.
- **Byte Pair Encoding (BPE)**: 모든 언어에 범용적으로 적용할 수 있는 워드피스(WordPiece) 서브워드 단위 생성 알고리즘으로, 빈도수가 높은 문자 쌍을 반복적으로 병합하여 어휘 사전을 구축합니다.
